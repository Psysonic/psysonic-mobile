# ⚠️ iOS territory (touch UI)

Runs in the iPhone/iPad app only: mounted behind `IS_IOS`. Bridges to CarPlay, Siri,
the home screen widgets, audio interruptions, the landscape lock and the app-update path
fix live here. What the widgets show is built in the shared `../widgets/`. Android's
counterpart is `../android/`; everything else in `mobileShell/` is shared by both apps.
See `MOBILE.md` in the repository root.
